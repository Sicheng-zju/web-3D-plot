# 3D 模型管理与查看系统

一个功能全面的 Web 端解决方案，用于管理、分享和查看 3D 工程文件。专为局域网离线部署设计，提供桌面级全屏体验。

## 功能特性

### 📂 文件管理
- **层级存储**: 创建文件夹和子文件夹来组织您的项目。
- **文件操作**: 轻松上传、移动、删除和重命名文件。
- **版本控制**: 更新模型的同时保留历史版本记录。
- **格式支持**: 针对工程格式（STL, STEP, IGES, OBJ 等）进行了优化。

### 🧊 3D 查看器
- **交互式查看**: 直接在浏览器中旋转、平移和缩放 3D 模型。
- **可视化工具**:
  - 标准视图切换（等轴测、前视图、顶视图等）
  - 线框模式
  - 透明度和颜色调整
  - 截图功能
- **属性面板**: 查看和编辑元数据（零件编号、材料、质量、供应商）及自定义属性。

### 🤝 协同工作
- **分享系统**:
  - **私有分享**: 将文件或文件夹分享给指定用户。
  - **公开分享**: 将文件发布到“公共画廊”，所有用户可见。
- **仪表盘**: 清晰区分“我的文件”和“与我共享”的文件。

### 🛠 技术亮点
- **离线就绪**: 所有依赖项（Bootstrap, Three.js）均已本地化打包，无需互联网连接即可运行。
- **桌面优先 UI**: 专为桌面生产力设计的全屏响应式布局。
- **双语支持**: 界面支持中英文一键切换。

## 安装指南

1. **克隆或下载** 本仓库。
2. **安装依赖**:
   ```bash
   pip install -r requirements.txt
   ```
3. **运行应用**:
   ```bash
   python app.py
   ```
4. **访问**: 打开浏览器并访问 `http://127.0.0.1:5000`。

## 项目结构

- `app.py`: Flask 应用主入口。
- `models.py`: 数据库模型（用户、文件、文件夹等）。
- `translations.py`: 本地化字典（中/英）。
- `templates/`: HTML 模板 (Jinja2)。
- `static/`:
  - `css/`: 自定义样式和响应式布局规则。
  - `js/`: 查看器逻辑和仪表盘脚本。
  - `vendor/`: 第三方库的本地副本 (Bootstrap, Three.js)。
- `uploads/`: 上传文件的默认存储位置。
- `instance/`: 首次运行后生成的 SQLite 数据库 (`db.sqlite3`)。
